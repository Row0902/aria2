## When to Use

- Calling any aria2 JSON-RPC method from the SDK client
- Understanding what a specific RPC method expects and returns
- Implementing new SDK methods that wrap aria2 RPC calls
- Handling aria2 notification events (push via WebSocket)
- Interpreting aria2 error codes and response formats
- Configuring aria2 daemon options via RPC
- Managing downloads, BitTorrent, and Metalink

## Critical Patterns

### JSON-RPC Protocol

aria2 exposes a JSON-RPC 2.0 interface over HTTP POST and WebSocket:

```json
// Request
{
    "jsonrpc": "2.0",
    "method": "aria2.addUri",
    "params": [["https://example.com/file.iso"], {"dir": "/downloads"}],
    "id": 1
}

// Success response
{
    "jsonrpc": "2.0",
    "result": "abc123def4567890",
    "id": 1
}

// Error response
{
    "jsonrpc": "2.0",
    "error": {
        "code": -32601,
        "message": "Method not found"
    },
    "id": 1
}

// Notification (WebSocket only, no id)
{
    "jsonrpc": "2.0",
    "method": "aria2.onDownloadComplete",
    "params": [{"gid": "abc123def4567890"}]
}
```

### Authentication (Secret Token)

If the daemon is started with `--rpc-secret=TOKEN`, prepend `token:TOKEN` as the first element of `params`:

```json
{
    "jsonrpc": "2.0",
    "method": "aria2.addUri",
    "params": ["token:$TOKEN", ["https://example.com/file"]],
    "id": 1
}
```

The SDK wraps this automatically — users just pass the secret to the client constructor.

### GID (Global ID)

All downloads are identified by a **GID** — a 32-character hex string:

```
abc123def4567890abc123def4567890
```

GIDs are generated by aria2 or can be specified by the client.

## RPC Methods — Complete Reference

### Download Addition

| Method | SDK Wrapper | Description |
|---|---|---|
| `aria2.addUri` | `add_uri(uris, options, position)` | Add HTTP(S)/FTP URI downloads |
| `aria2.addTorrent` | `add_torrent(torrent, uris, options, position)` | Add BitTorrent download (torrent as base64 bytes) |
| `aria2.addMetalink` | `add_metalink(metalink, options, position)` | Add Metalink download (metalink as base64 bytes) |

```python
# addUri: uris = list of mirror URIs
gid = await client.add_uri([
    "https://mirror1.example.com/file.iso",
    "https://mirror2.example.com/file.iso",
], options={"dir": "/downloads", "split": "4"})

# addTorrent: torrent file as bytes
with open("file.torrent", "rb") as f:
    gid = await client.add_torrent(f.read())

# addMetalink: metalink file as bytes
with open("file.meta4", "rb") as f:
    gid = await client.add_metalink(f.read())
```

**Parameters:**

| Param | Type | Required | Description |
|---|---|---|---|
| `uris` | `list[str]` | ✅ | URIs to download |
| `torrent` | `bytes` (base64) | ✅ | Torrent binary → base64 |
| `metalink` | `bytes` (base64) | ✅ | Metalink binary → base64 |
| `options` | `dict[str, str]` | ❌ | aria2 options (see below) |
| `position` | `int` | ❌ | Position in queue (0 = first) |

### Download Control

| Method | SDK Wrapper | Description |
|---|---|---|
| `aria2.remove` | `remove(gid)` | Remove a download (active/waiting) |
| `aria2.forceRemove` | `remove(gid, force=True)` | Remove without cleanup |
| `aria2.pause` | `pause(gid)` | Pause a download |
| `aria2.forcePause` | `pause(gid, force=True)` | Force pause |
| `aria2.pauseAll` | `pause_all()` | Pause all downloads |
| `aria2.forcePauseAll` | `pause_all(force=True)` | Force pause all |
| `aria2.unpause` | `unpause(gid)` | Resume a paused download |
| `aria2.unpauseAll` | `unpause_all()` | Resume all paused |
| `aria2.changePosition` | `change_position(gid, pos, how)` | Move download in queue |

```python
# Remove
await client.remove(gid)
await client.remove(gid, force=True)

# Pause / Resume
await client.pause(gid)
await client.pause_all()
await client.unpause(gid)

# Change position
new_pos = await client.change_position(gid, -1, PositionHow.CUR)
new_pos = await client.change_position(gid, 0, PositionHow.SET)
```

**`change_position` `how` values:**

| Value | Meaning |
|---|---|
| `POS_SET` | Absolute position from start |
| `POS_CUR` | Relative to current position |
| `POS_END` | From the end (pos=0 is last) |

### Download Status

| Method | SDK Wrapper | Description |
|---|---|---|
| `aria2.tellStatus` | `tell_status(gid, keys)` | Get download details |
| `aria2.tellActive` | `tell_active(keys)` | List active downloads |
| `aria2.tellWaiting` | `tell_waiting(offset, num, keys)` | List waiting downloads |
| `aria2.tellStopped` | `tell_stopped(offset, num, keys)` | List stopped/complete downloads |
| `aria2.getFiles` | `get_files(gid)` | Get file list for download |
| `aria2.getUris` | `get_uris(gid)` | Get URIs for download |
| `aria2.getServers` | `get_servers(gid)` | Get server info (HTTP/FTP) |
| `aria2.getPeers` | `get_peers(gid)` | Get peer list (BitTorrent) |

```python
# Full status
status = await client.tell_status(gid)
print(f"Progress: {status.completed_length}/{status.total_length}")
print(f"Speed: {status.download_speed} bytes/s")

# With keys filter (reduced payload)
status = await client.tell_status(gid, keys=["gid", "status", "downloadSpeed"])

# Lists
active = await client.tell_active()
waiting = await client.tell_waiting(0, 10)  # first 10 waiting
stopped = await client.tell_stopped(0, 50)  # last 50 stopped
```

**`tellStatus` response fields (key ones):**

| Field | Type | Description |
|---|---|---|
| `gid` | `str` | 32-char GID |
| `status` | `str` | `active`, `waiting`, `paused`, `error`, `complete`, `removed` |
| `totalLength` | `str` | Total length in bytes (as string) |
| `completedLength` | `str` | Completed length in bytes |
| `downloadSpeed` | `str` | Download speed in bytes/sec |
| `uploadSpeed` | `str` | Upload speed in bytes/sec |
| `connections` | `str` | Number of connections |
| `numSeeders` | `str` | Number of seeders (BT only) |
| `files` | `list` | Downloaded files |
| `bittorrent` | `dict` | BitTorrent metadata |
| `errorCode` | `str` | Error code if status=error |
| `errorMessage` | `str` | Error message if status=error |
| `dir` | `str` | Directory where file is saved |
| `infoHash` | `str` | BitTorrent infohash |
| `pieceLength` | `str` | Piece length in bytes |
| `numPieces` | `str` | Number of pieces |

### Options (Get/Change)

| Method | SDK Wrapper | Description |
|---|---|---|
| `aria2.getOption` | `get_option(gid)` | Get options for a specific download |
| `aria2.changeOption` | `change_option(gid, options)` | Change options for a download |
| `aria2.getGlobalOption` | `get_global_option()` | Get global daemon options |
| `aria2.changeGlobalOption` | `change_global_option(options)` | Change global daemon options |

```python
# Per-download options
opts = await client.get_option(gid)
await client.change_option(gid, {"max-download-limit": "100K"})

# Global options
global_opts = await client.get_global_option()
await client.change_global_option({"max-concurrent-downloads": "5"})
```

## Notifications (WebSocket Events)

When using WebSocket transport, aria2 sends push notifications:

| Notification | SDK Event | Payload |
|---|---|---|
| `aria2.onDownloadStart` | `on_download_start(callback)` | `{"gid": "..."}` |
| `aria2.onDownloadPause` | `on_download_pause(callback)` | `{"gid": "..."}` |
| `aria2.onDownloadStop` | `on_download_stop(callback)` | `{"gid": "..."}` |
| `aria2.onDownloadComplete` | `on_download_complete(callback)` | `{"gid": "..."}` |
| `aria2.onDownloadError` | `on_download_error(callback)` | `{"gid": "..."}` |
| `aria2.onBtDownloadComplete` | `on_bt_download_complete(callback)` | `{"gid": "..."}` |

```python
async with Aria2Client(secret="token", enable_ws=True) as client:
    def on_start(gid: str) -> None:
        print(f"Download started: {gid}")

    def on_complete(gid: str) -> None:
        print(f"Download complete: {gid}")

    client.on_download_start(on_start)
    client.on_download_complete(on_complete)

    gid = await client.add_uri(["https://example.com/file.iso"])
    await asyncio.sleep(10)  # Receive events
```

## File Info Structure

`getFiles` returns a list of:

```python
class FileInfo(BaseModel):
    index: str              # File index in torrent/metalink
    path: str               # Full path to file
    length: str             # File length in bytes
    completed_length: str   # Downloaded bytes
    selected: str           # "true" if selected for download
    uris: list[UriInfo]     # URIs for this file
```

Each URI entry:

```python
class UriInfo(BaseModel):
    uri: str                # The URI
    status: str             # "used" or "waiting"
```

## Best Practices for SDK Integration

### 1. All numeric fields are strings
aria2 returns EVERY numeric field as a string: `"totalLength": "1048576"`. Never convert in models.

### 2. Use keys parameter to reduce payload
`tell_status(gid, keys=["gid", "status", "downloadSpeed"])` reduces response size.

### 3. Token-first params
When secret is set, the token goes FIRST in params: `["token:secret", param1, param2]`.

### 4. Position management
- `position=-1` with `POS_END` → second to last
- `position=0` with `POS_SET` → first in queue
- `position=-1` with `POS_CUR` → move one spot earlier

### 5. Force methods
`forceRemove`, `forcePause`, `forceShutdown` skip cleanup operations. Use when daemon is unresponsive.

### 6. Poll vs push
- Use `tellActive()` for polling (HTTP transport)
- Use event callbacks for push (WebSocket transport)

### 7. Error handling
Map RPC errors to typed exceptions. Common patterns:
- `-32602` → invalid params (missing GID, wrong type)
- `-32001` → app error (too many requests, download already exists)

## Common Pitfalls

- **GID format**: Always 32 hex characters. aria2 generates them, but clients can pass custom GIDs via `aria2.addUri` with `gid` option.
- **Base64 encoding**: `addTorrent` and `addMetalink` expect base64-encoded bytes, not raw bytes.
- **Options are strings**: `{"split": 5}` is wrong. Use `{"split": "5"}`.
- **Notification order**: WebSocket notifications arrive asynchronously. Don't assume they arrive in order.
- **`tellStatus` on removed downloads**: Returns `{"error": {"code": -32602}}` if GID doesn't exist.
- **K in options**: Speeds use `K` (1024), `M` (1024^2), not `KB`, `MB`.

aria2c --enable-rpc --rpc-listen-all --rpc-secret=TOKEN
